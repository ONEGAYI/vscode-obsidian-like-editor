# AI 单图生成快速操作图标

## 执行资格

**这套流程必须交给 Codex（ChatGPT）会话执行。**开始前先核对当前运行环境。若不是 Codex（ChatGPT），立即调用 `$matt-skills-curated:handoff`，将需求、项目与目标工作树、现有图标参考、已定图标 key、验收约束及下一步命令写入系统临时目录的交接文件，然后停止生图和资产改动。本机该技能的已知位置是 `C:/Users/64487/.codex/plugins/cache/openai-curated-remote/matt-skills-curated/1.1.0/skills/handoff/SKILL.md`；路径失效时按技能名查找。若无法调用，说明移交未完成，不以其他模型或手工绘图代替。

在 Codex（ChatGPT）中，先读取 `imagegen` 技能并使用内置生图工具。此项目技能只用于用户要求 **AI 单图生成、裁切、SVG 化** 的图标任务；其他图标修改依现有可编辑源文件和用户要求处理。

## 项目入口

- 以 `scripts/quick-action-icons.py` 的 `KEYS`、`COLORS`、`validate` 和 `build` 为产物契约；以 `media/quick-actions/README.md`、`contact-sheet.png` 及现有明暗图标为风格参照。
- 先确认目标工作树和已有改动。主工作树留给用户；在独立工作树制作。若用户指定了特性工作树，交付阶段主动同步到该工作树，并核对其状态，不让接手者手动搜集文件。
- 概念、key、主题和输出格式未明确时先从规格或交接材料确认；不要用生成图猜操作语义。

## 制作与集成

1. **合并生图**：把现有代表性图标排成参考板，为全部新增图标在同一张图中留独立格。一次调用内置生图工具生成整张图；需要修正时编辑同一张图，最终只选一张原图作为裁切来源。提示词约束单色、极简线稿、现有笔画粗细与圆角、18px 可读性，并排除文字、渐变、阴影与装饰。保留最终原图供追溯。
2. **裁切源图**：只从最终原图的目标格取图。去除参考板边框、背景噪点与杂色；保持长宽比，居中放入 96×96 安全区。将新增图标按 key 顺序拼成一张 RGBA 源图，每格 96×96，透明背景、单色墨水、二值 alpha。记录格位顺序与必要的裁切说明；不把原始生成图直接交给 VTracer。
3. **接入生成器**：让 `draw_icon` 从单张源图按格裁切 alpha，再分别着 `COLORS` 中的明暗主题色。更新 `KEYS`；运行 `python scripts/quick-action-icons.py`，由既有流程裁切 PNG、调用开源 VTracer 提取真实 SVG path，并执行 `validate`。不要手写最终 SVG 或内嵌栅格图。新增文件和源图放在 `media/quick-actions/`，并更新该目录的 README。
4. **视觉与文件校验**：把新图标与既有图标并列，分别在浅色、深色背景上查看 96px 和实际工具栏 18px 效果。核对语义、线重、留白与辨识度；有问题先修正生成图或裁切源图，再重建。确认既有图标文件未意外改变、总览尺寸与键数正确、PNG 色值/透明度/安全区通过、SVG 有非空 path 且无位图嵌入。维护项目 file-tree 数据源并报告任何既有校验告警。

## 交付

给出最终原图、单张裁切源图、总览和新增 PNG/SVG 的位置，以及生图提示词、所用工具、验证结果和未核实的视觉问题。资产应落在指定工作树；远端推送仍遵循项目授权边界。
