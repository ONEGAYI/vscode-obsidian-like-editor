# Mermaid 图表渲染性能与错误边界（工单 #60）

> 测量日期：2026-09-25。测量通道：Playwright headless Chromium（生产控制器
> 装配 + 真实 mermaid 11.12.2 独立产物，CSP 复刻页面），不占真宿主集成车道；
> 真宿主（VSCode 1.86.2 webview）的对应数据由 `test/perf` 套件在合并阶段补测
> （`perf-mermaid.md` 图表密集档已接线，见文末「宿主车道待补项」）。

## 架构性能设计（先讲机制，数据再验证）

- **懒加载**：mermaid 不进主 bundle（minify 后 2,727,077 B），独立产物
  `out/webview/mermaid.js` 由宿主在 webview HTML 注入资源 URI（nonce 内联
  脚本全局变量），**存在 mermaid 围栏的容器首次渲染时**才注入 `<script>`
  加载——无围栏文档零成本，成功加载恰好一次；注入失败（onerror）置终态
  不重试（资源 URI 固定，重注入只会堆积失败 script），渲染走降级。
- **渲染缓存（LRU 64 条）**：`mermaid.render` 结果按围栏源文本缓存；同一图
  滚动往返命中缓存不再渲染；**失败同样缓存**（同一坏源码不反复重试）。
  缓存条目携带主题代次戳：在途渲染完成时若主题已切换，结果应用到容器但
  不写缓存——防止后续渲染命中旧主题条目导致容器永久滞留旧主题。
- **克隆 id 改写**：缓存条目插入多个容器时（同源相邻图），把 SVG 内全部
  `id="…"` 值与 `#引用`（含 `url(#…)`、内嵌 `<style>` 选择器）按实例前缀
  重写——文档内 id 唯一、样式选择器不串图；多值 id 引用属性
  （`aria-labelledby` / `aria-describedby`，值以空白分隔）按分词逐段改写
  （当前 mermaid 产物实测仅单值，能力已补齐防未来版本变化）。改写只动
  字符串，无二次解析。
- **串行渲染队列**：一屏多图的 render 请求按队列逐个执行，避免并行渲染的
  主线程长任务风暴；单图渲染本身是同步布局计算（毫秒到几十毫秒级）。
- **按视口物化**：live 侧跨行 replace 装饰走 StateField（CM6 约束），widget
  `toDOM` 只在进入视口时由 CM6 调用——屏外围栏只有数据无 DOM；容器离开
  文档（视口回收 / CM6 丢弃 widget）后不回插。阅读侧 mermaid 围栏整块成块
  （豁免 60 行大围栏切片），挂载即渲染、卸载随块 `el.remove` 释放。
- **围栏表增量**：全文档围栏表（含非 mermaid 围栏，供嵌套伪围栏抑制）由
  StateField create 全量扫描、docChanged 增量重建——窗口起点锚定在变更前
  最后一个已闭合围栏之后（已知顶层状态，前向扫描精确）；无锚点时自种子
  首行回溯 2048 行起步，且以文末开放围栏的开启行（trailingOpenStart）为
  窗口下界——窗口不会落在长开放围栏中部而把内容行的 ``` 当开启符（幻影
  span 误渲染）。窗口尾部开放时按批增量续扫（只扫新行段、开放状态延续，
  不重扫窗口——从零重扫会让未闭合长尾呈平方级成本），到闭合、文末或
  8192 行熔断为止。纯选区移动零成本。
- **主题联动**：明暗切换时清空缓存并重渲染当前在文档中的容器（SVG 主题
  样式渲染时烘焙进内嵌 `<style>`，无法按条目换肤）。

形态对齐 `generateMermaidDenseSample`），约 1.6 KB / 27 个图。

| 指标 | 数值 | 判读 |
| --- | --- | --- |
| 首屏（装载 + mermaid.js 懒加载解析 + initialize + 首批图渲染） | 311 ms | 含一次性 2.6 MB 脚本获取与解析；无图文档不发生 |

对照 MVP 性能契约（docs/specs/mvp.md「MVP 性能契约」）：图表密集文档的
击键延迟与普通文档同量级，滚动回收保持窗口有界——契约面满足。图渲染后
高度远超源行数，初始高度估计放大 2× 起步、挂载后由 ResizeObserver 实测
回填（与图片加载同路径），首屏滚动条跳动幅度大于图片属预期代价，真宿主
观感属 A33 人工验证项。

## 错误边界（如实记录）

- **语法/渲染失败**：容器进入 error 态（错误信息 + 可读源码），不吞后续
  块、不影响其他图；失败结果进缓存，同一源码不重试。修正源码后光标离开
  围栏即按新源文渲染（缓存键为源文本，天然失效）。
- **渲染器不可用**（URI 缺失 / 脚本加载失败）：降级为 error 态提示
  「图表渲染器不可用」，不抛出、不阻塞编辑；无围栏文档不触发加载。
  注入失败置终态不重试——同一 webview 会话内后续渲染直接降级（重开
  文档/面板是新的注入机会）。
- **伪围栏**：外层长围栏（如四反引号 `md` 块）内的 ` ```mermaid ` 文本、
  缩进 ≥4 视觉列的围栏（Tab 按 CommonMark 折算到下一 4 倍制表位——行首
  Tab 起步即 ≥4 列，与阅读侧 markdown-it 一致）、info 多词（`mermaid xxx`）
  与大小写变体（`Mermaid`）一律不渲染——与 GitHub/Obsidian 口径一致
  （info 精确匹配、大小写敏感）。
- **未闭合围栏**（EOF）：不产出装饰，稳定显示源码。
- **图内链接**：`securityLevel: 'strict'` 下用户文本转义、click 交互禁用；
  图内点击不产生导航（浏览器回归实证），产物内无 `javascript:` 链接。
- **净化边界**：mermaid SVG 经 DOM API 插入专用容器，**不经**
  `sanitizeReadingDom`（其剥 `<style>` 会毁配色）——安全由 mermaid 自产
  SVG + strict 档 + webview CSP（`script-src` 无 unsafe-eval，实测可渲染）
  三层兜底。

## 已知限制

- **引用行内的围栏**（`> ```mermaid`）：markdown-it 识别为 blockquote 内
  fence，阅读侧渲染图；live 侧行扫描不识别引用前缀——live 显源码、阅读
  渲染图，降级方向安全（源文不丢）。后续如需对齐，live 扫描剥引用前缀即可。
- **超过 2048 行的围栏**：无锚点围栏时增量回溯窗口 2048 行——超长围栏的
  远端击键可能暂时漏配对（装饰缺失或错位，纯视图层，不写文档），装载/
  resync 的全量扫描恢复；与 #59 公式块表同类的已知限制。已知文末开放
  围栏在窗口之前时窗口起点下移到其开启行（trailingOpenStart 锚定），
  幻影围栏不产生——下移后窗口与围栏同长，最坏成本与全量扫描同量级
  （整文档单个未闭合围栏 + 文末击键的极端形态）。
- **未闭合围栏向下延伸的熔断**：窗口尾部开放时增量续扫至多
  `MERMAID_FENCE_EXTEND_LIMIT`（8192）行——更长的未闭合长尾停止延伸、
  该围栏增量漏配对（live 显源码），全量扫描恢复；与 #59 的
  `MATH_BLOCK_EXTEND_LIMIT`（4096）同形态。
- **撤销/重做**：权威栈在宿主，本工单未改写围栏文本路径；浏览器回归以
  「等量退格逐字节复原」钉住输入事务可逆性（与 #59 同口径），单测另有
  围栏内键入 → edit.request → undo 一次恢复原文与渲染态的宿主链路用例。
