# 人工验证清单（MVP 收尾交付）

状态：2026-09-24，工单 #15 汇编。本清单收录**自动化测试无法替代的人工验证项**——真实 IME 候选窗、物理键盘手感、真实远程宿主与真实浏览器等。每项给出步骤与预期结果；执行时逐项勾选记录，未执行项保持「待验证」状态。

> 边界申明：**代理自检不等于用户验收**。集成自动化（54 例，真实 1.86.2 宿主）与性能实测见[性能档位汇总](../perf/2026-09-mvp-performance-summary.md)；本清单之外的全部功能行为已有自动化用例覆盖。

## 通用准备

- 安装 VSIX（`vscode-obsidian-like-editor-0.1.0.vsix`）到 VSCode 1.86+：命令面板 →「Extensions: Install from VSIX…」。
- 打开方式：对 `.md` 文件右键 →「打开方式…」→「Obsidian-like Markdown Editor」（默认打开仍是原生文本编辑器，不自动接管）。
- 切换视图：命令面板 →「Obsidian-like Markdown Editor: 切换实时预览与阅读模式」，或编辑器工具栏按钮。

## 一、输入与组合（#3 / #12 / #13）

### A1. 中文 IME 真实组合输入（#3）

1. live 视图任意段落输入中文（拼音候选窗选词、连续多轮组合、组合中途 Esc 取消）。
2. 组合期间观察候选窗位置跟随光标、无闪烁跳动。

预期：候选词上屏文本正确写入并保存后回读一致；组合中途外部修改该文件（另一编辑器改同一行），上屏不被打断且冲突按「保留输入」语义处理（顶部出现冲突横幅，本地输入保留）。

### A2. 日文 IME 组合输入（#3）

1. 添加日文输入法，live 视图输入假名并转换为汉字（确认Enter上屏与 Tab 确认候选两条路径）。

预期：与 A1 同语义，无错字、无丢字、无重复上屏。

### A3. 表格内真实键盘/IME 输入（#12）

1. 打开含表格的文档（如 `| a | b |` 一行起始两列表）。
2. 光标进入表格行，连续键入 `|` 观察自动转义为 `\|`（单元格内）。
3. 在表格单元格内用中文 IME 输入长文本、粘贴含 `|` 的文本。

预期：键入的 `|` 被转义且光标落在转义符之后；粘贴的裸 `|` 保持原样写入（已知不自动转义，属记录在案的行为）；IME 在单元格内组合正常。

### A4. 表格 Tab 物理按键手感（#13）

1. 光标置于表格单元格内，按 Tab / Shift+Tab 在单元格间移动。
2. 在行末单元格按 Tab（新增行）、行首按 Shift+Tab；在表格最后一行的行末按 Tab。
3. 命令面板执行六个「表格：…」命令确认可见性与快捷入口。

预期：Tab 移动光标流畅无迟滞；行末 Tab 新增行后光标落位新行首格；非表格上下文 Tab 保持原生缩进语义；命令面板可检索到全部六个表格命令。

### A5. IME 组合中按 Tab 的事件序列（#13）

1. 在表格单元格内启动 IME 组合（候选窗活跃），按 Tab。

预期：Tab 归属 IME 候选选择而非单元格导航（组合不被打断、不发生导航跳格）；组合结束后再按 Tab 恢复导航语义。

### A6. 表格增删行列后滚动落位（#13）

1. 长文档中的表格（表格上方有数百行内容），滚至表格处。
2. 执行增删行列命令，观察视口。

预期：命令执行后视口不跳到文档顶部，表格区域保持在视野内；一次 Ctrl+Z 撤销一笔完整操作。

## 二、任务勾选（#9）

### A7. 真实鼠标点击 checkbox（#9）

1. live 视图与 reading 视图分别用鼠标点击任务项 checkbox（含相邻重复任务文本的场景）。
2. 用 Tab 把焦点移到 checkbox，按空格激活。

预期：点击/空格只翻转目标项；重复文本的任务项只改正确的一个；Ctrl+Z 撤销一次勾选；reading 视图点击后正文仍不可编辑。

### A8. 长文档滚动中勾选视觉稳定（#9）

1. 打开长文档（数千行以上任务列表），滚动中勾选视口内任务项。

预期：勾选写回后无滚动跳动、无视觉闪变（源位置锚定生效）。

## 三、链接与图片（#10）

### A9. 真实外开浏览器（#10）

1. live 视图 Ctrl+单击 `https://` 链接；reading 视图单击同一链接。

预期：系统默认浏览器打开目标页；`file://`、`javascript:` 等危险 scheme 被拦截并给出可见反馈（非静默失败）。

### A10. 鼠标手感（#10）

1. live 视图对链接/图片区域使用鼠标：悬停、单击、Ctrl+单击、拖选文本。

预期：普通单击不触发跳转（进入编辑）；Ctrl+单击跳转；拖选不经误触链接；悬停样式与普通文本可区分。

### A11. 真实 SSH 宿主图片显示（#10）【需远程环境】

1. 通过 Remote SSH 连接 Linux 宿主，安装同一 VSIX，打开含工作区相对路径图片（中文与空格文件名）的文档。

预期：图片经宿主通道在 webview 正常显示；缺失图呈现可重试错误态而非空白。

## 四、双链（#11）

### A12. 真实 SSH 宿主双链（#11）【需远程环境】

1. Remote SSH 会话中打开含 `[[目标笔记]]`、`[[目录/目标|别名]]`、`[[目标#标题]]` 的文档。
2. live 视图 Ctrl+单击双链；reading 视图单击。

预期：按名/路径/别名/标题四种形态均能解析并打开正确目标；目标在文本编辑器打开时光标 reveal 到标题行。

### A13. QuickPick 歧义弹窗手感（#11）

1. 工作区内制造同名笔记（不同目录），触发指向该名的双链。

预期：弹出候选 QuickPick，键盘上下选择与 Enter 确认流畅、Esc 取消不跳转。

### A14. 无工作区提示呈现（#11）

1. 不打开任何文件夹（空窗口）直接打开单个 `.md`，触发双链跳转。

预期：给出「无工作区无法解析」类的可见提示，不崩溃、不静默无响应。

## 五、滚动与回收（#12）

### A15. 滚动回收未确认输入（#12）

1. live 视图在表格单元格输入但不保存，快速滚动远离该表格再滚回。

预期：输入内容保留（CM6 状态不因视口回收丢失）；保存后磁盘回读与所见一致。

### A16. 表格视觉（#12）

1. 对照 live 与 reading 视图查看同一表格：对齐（` :---: `/` ---: `）、行内代码单元格、转义管道单元格。

预期：reading 以真实 table 呈现对齐语义；live 源文一维布局不重排（所见即所键）；已知渲染偏差（行内代码内 `|` 的单元格切分）与 [table-cell-editing.md](../perf/2026-09-table-cell-editing.md) 记录一致。

## 六、安装与远程环境（#15）

### A17. 日常使用 VSCode 安装实测

自动化已覆盖安装态回归：VSIX 经 CLI `--install-extension` 真实安装进 1.86.2 便携宿主的隔离扩展目录（安装注册链路），再以安装解压产物为扩展来源跑通全部 54 集成用例（见 `test/integration/runInstalled.mjs`；1.86 测试模式要求 extensionDevelopmentPath 存在，故 dev path 指向安装解压目录，加载代码仍是 VSIX 产物）。本项验证**日常使用的真实 VSCode 实例**：

1. 在自己日常使用的 VSCode（1.86+）安装 VSIX，重启。
2. Reopen With 打开日常笔记文档，编辑、保存、关闭、重开。

预期：安装无报错；扩展出现在已安装列表；重开后内容与保存时一致；卸载后 `.md` 恢复原生打开。

### A18. CentOS 7 Remote SSH 最小烟测【当前未验证】

1. 准备 CentOS 7 远端（glibc 等系统库保持旧版，不升级——ADR-0001 约束），本地 VSCode 1.86 经 Remote SSH 连接。

预期：扩展在远端扩展宿主激活，上述操作行为与本地一致；webview 由本地渲染，远端只跑宿主侧代码。
