## 通用准备

- 安装 VSIX（`vsidian-0.1.0.vsix`）到 VSCode 1.86+：命令面板 →「Extensions: Install from VSIX…」。
- 打开方式：安装后打开 `.md` 文件默认进入 Vsidian（#38 起注册为默认编辑器）；改回原生用右键「打开方式…」选文本编辑器，或「Reopen With… → Configure default editor for '*.md'…」修改关联设置。
- 切换视图：编辑器标题栏三态按钮（实时预览 → 阅读 → 源码编辑器循环，只显示下一步的图标与提示），或命令面板 →「Vsidian: 切换到下一视图模式」及三个显式目标命令。

## 八、标题栏三态切换与全局模式记忆（#38）

### A21. 三态按钮循环、多标签独立、重启恢复与未保存保留

1. **三态循环与图标/提示**：打开一个 `.md`（默认进入 Vsidian 实时预览），观察编辑器标题栏按钮——实时预览态显示「切换到阅读模式」（书本图标），点击进入阅读；阅读态显示「切换到源码编辑器」（代码图标），点击切到原生源码编辑器；源码态显示「切换到实时预览」（铅笔图标），点击回到实时预览。命令面板执行「Vsidian: 切换到下一视图模式」应走同一循环。
2. **多标签各态独立**：开两个 `.md` 标签，A 切到阅读、B 保持实时预览；点击标题栏按钮时只作用于当前活动标签，另一标签状态不变。
3. **重启恢复与全局记忆**：切到阅读模式后关闭面板，打开另一个 `.md` 应直接进入阅读；切到源码编辑器后新开 `.md` 应落在原生编辑器。重启 VSCode 后该记忆仍生效；若窗口重开时恢复的 Vsidian 标签在源码记忆下被弹回原生，点铅笔按钮一步切回即属预期。
4. **未保存内容跨切换保留**：实时预览输入若干文字不保存，依次切到源码编辑器再切回——未保存内容全程可见、文件仍为 dirty、磁盘未被写入（纯视图切换不隐式保存）。
5. **diff 视图无按钮**：对两个 `.md` 执行「比较选中」（或在 SCM 更改列表点开 `.md`），对比视图的标题栏不出现三态按钮；此时执行命令面板切换命令应提示「对比视图不支持视图切换」且不改变对比视图。
6. **IME 组合未上屏时切换（#38 评审补充）**：在实时预览用中文输入法输入到组合态（拼音未上屏），直接点击标题栏三态按钮切到源码编辑器，再切回实时预览——组合文本应不丢失，或按项目冲突保留约定处理（出现「未确认输入已保留」类提示可取回）。自动化覆盖说明：组合中收到 `view.mode.set` 不打断组合缓冲链路（提交与 flush 照常、切回后输入保留）已有 jsdom 单测钉死；真实浏览器在容器切换时对未上屏拼音的处置无法无头模拟，须在此人工验证。
7. **双 Vsidian 标签的按钮随焦点切换（#38 评审补充）**：开两个 Vsidian 标签，A 处于实时预览、B 切到阅读模式；在两个标签间切换焦点——标题栏按钮应随活动标签变化（A 显示书本、B 显示代码图标）。此构型在 1.86 无头测试宿主下第二个 webview 面板创建偶发不就绪（约 5/7 轮复现，环境 flaky），集成用例已降级为「Vsidian 面板 + 原生 .md 标签」构型，双面板各自模式独立与按钮联动依赖本人工项。

预期：三态循环方向恒为 实时预览 → 阅读 → 源码 → 实时预览；按钮只显示下一步的目标；模式记忆为最近一次成功切换（跨窗口、重启保留）；已知代价——记忆停留在源码态时显式「Reopen With → Vsidian」会被弹回原生，铅笔按钮可一步切回。

## 已知限制（如实记录）

- **全局记忆停留在源码态时的显式打开被弹回**（#38）：Vsidian 默认接管 `.md` 打开后，记忆为源码态时新开（含显式「Reopen With → Vsidian」与窗口恢复的 Vsidian 标签）会被弹回原生编辑器——扩展无法区分默认关联与显式指定。可点标题栏铅笔按钮一步切回；经「Reopen With… → Configure default editor for '*.md'…」改回原生关联不受影响。
- **diff 对比视图不支持三态切换**（#38）：对比视图（SCM 更改、比较选中）的标题栏不显示三态按钮，命令面板切换命令在 diff 语境为 no-op 加提示，对比完整性优先。
- **超长行与图片密集场景已有单机专项**（#23）：结构、实测结果及边界见[性能档位汇总](../perf/2026-09-mvp-performance-summary.md)。大型位图解码内存和图片加载瞬时峰值仍未覆盖。
- **双链目标面板含未确认输入时的标题定位基准**（#11）：目标文档在另一编辑器面板打开且该面板含未确认（未保存）输入时，标题定位以 `TextDocument` 权威文本为基准，可能与面板可见内容错位；窗口过小等极端场景下定位 clamp 保证不越界。
- **歧义双链并发触发时 QuickPick 单例替换行为**（#11）：两个歧义双链几乎同时触发跳转时，后发的候选 QuickPick 会替换先发者（VSCode QuickPick 为单例），先发跳转被放弃——该并发路径的自动化覆盖有限，行为以人工使用观察为准。
- **快速关闭与远端断连仍需真实操作复核**（#21/#27）：暂停和暂缓态的输入现已即时上报宿主快照；单测与 1.86.2 宿主集成用例验证关闭通知含最后一笔。真实 Ctrl+W 操作与 CentOS 7 Remote SSH 断连后恢复尚未由人工执行，不据此宣称跨环境通过。
