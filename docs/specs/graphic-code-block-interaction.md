# 规格：图形化代码块交互（按钮、图表弹窗与导出）

状态：草案，2026-09-26。设计共识经 grill 访谈确认；实施工单 [#111 图形化代码块交互重做](https://github.com/ONEGAYI/vsidian/issues/111)，关联 [#110 Mermaid 暗色主题修复](https://github.com/ONEGAYI/vsidian/issues/110)（不属本规格范围，两票变更面不相交、可并行）。参考 [vscode-office](https://github.com/cweijan/vscode-office)（本地 `D:/CODE/Project/_Extensions/vscode-office`）的交互实现，**只借鉴交互与结构，不复用其代码**。本文是图形化代码块交互的单一事实源，实施工单的验收以此为准。

## 范围

- **覆盖**：图形化代码块的**呈现态**（渲染图形显示时）在 Live 视图与阅读视图的交互——右上角按钮组、禁点击进编辑、图表弹窗、导出。「图形化代码块」定义见 CONTEXT.md 词表：内容整体渲染为图形的围栏代码块，现仅 `mermaid`（#60 专属管线）。
- **机制注册表化**：按钮组、弹窗、禁点击是路径级行为，由图形化代码块渲染器注册表统一供给；后续同类渲染器（如 PlantUML）登记即继承全部行为。本规格只有 mermaid 一个消费者，通用性以契约测试与接入清单文档兜底，不引入第二渲染器依赖。
- **固定排除**：`$$` 块级公式行为保持现状（Live 点击进编辑不变），本票不动、暂不开票；无效语法降级态（错误提示框）不显示按钮；编辑态（光标在围栏内、源码显形）仍走代码块卡片外壳（#78–#85），不在本规格内改动。
- **非目标**：弹窗内编辑源码、弹窗内容随文档编辑实时同步、主题切换按钮（主题自动跟随编辑器，另票处理取值）、WebviewPanel 新标签页载体、剪贴板复制图片。

## 已确认交互契约

1. **按钮组**：渲染图形右上角、悬停显示——悬停前不可见、不占位；`edit`（编辑源码）居左、仅 Live 视图；`popup`（弹窗预览）居右、Live 与阅读两视图皆有。纯图标按钮，aria-label 提示，文案走 `t()`。
2. **禁点击进编辑**：呈现态渲染图吞掉点击——点击图形不再把光标落进围栏、不触发源码显形；编辑入口收敛到 `edit` 按钮。阅读视图渲染图点击本无行为，维持无副作用。
3. **edit 语义**：点击后光标定位到该围栏、进入编辑态（源码显形、代码块卡片接管外壳）——即原「点击图片进入编辑」行为的显式化迁移，对齐参考实现的防误触收敛。
4. **图表弹窗（载体与内容）**：webview 内全屏模态浮层，覆盖当前视图；打开期间正文不可交互，关闭后焦点归还原焦点元素。内容为**打开时快照**（按围栏源码经渲染管线取得，缓存优先）；工具条含**刷新**按钮，按当前文档源码重渲染取新图（应对外部变更等导致的源码变化），不做自动同步。
5. **弹窗浏览能力**：滚轮缩放（以光标位置为锚点）、键盘 `+`/`-`/`0`（缩放/重置）、方向键平移、左键拖拽平移、工具条 zoom-out/百分比/zoom-in/重置；初始 contain-fit 整图可见并留边；Esc、点击空白区、工具条 close 关闭。缩放写 SVG 的 width/height（viewBox 矢量重排，任意倍率文字保持清晰），transform 只承担平移——不得用 `transform: scale()` 光栅化拉伸。
6. **导出**：SVG 与 PNG 文件。SVG 走矢量序列化（固化内在尺寸、补全命名空间）；PNG 在 webview 内光栅化。经消息协议请求宿主弹出另存为对话框后落盘，宿主侧做载荷校验。**PNG 光栅化受 webview CSP 约束，为本票显式风险项**：实现前先验证，受阻则降级为仅 SVG 并回报，不阻塞其余交付。
7. **键盘边界**：弹窗打开期间，缩放/平移/关闭按键只在弹窗内生效，不进入 CM6 正文、不接管宿主绑定。弹窗局部键不登记宿主快捷键绑定入口（类比查找会话的局部键，已按「操作与快捷键注册」约定评估记录）。
8. **一致性与同步**：模式切换、主题明暗切换、外部文档同步期间弹窗与按钮不得错位、串图或悬挂；弹窗快照与刷新遵循现有 LF 坐标与增量写回规则，不产生写回与撤销历史。

## 用户故事

1. 作为编辑者，我希望点击渲染图不会误入编辑态，从而安心浏览图表内容。
2. 作为编辑者，我希望悬停渲染图出现「编辑源码」按钮、点击即进入该围栏编辑，从而编辑入口明确且不丢。
3. 作为读者，我希望在阅读视图悬停图表出现「弹窗预览」按钮，从而放大查看细节。
4. 作为读者，我希望弹窗支持滚轮/按钮/键盘缩放与拖拽平移，从而任意倍率下看清图的每个局部。
5. 作为读者，我希望缩放后文字仍然清晰（矢量重排而非位图拉伸），从而高倍率下不糊。
6. 作为读者，我希望文档被外部更新后能在弹窗内点「刷新」取新图，从而不必关闭重开。
7. 作为用户，我希望把图表导出为 SVG 文件，从而在其他工具中无损复用。
8. 作为用户，我希望把图表导出为 PNG 文件，从而贴进不支持 SVG 的场合。
9. 作为贡献者，我希望新增图形化渲染器只需登记注册表，从而按钮、弹窗、禁点击自动继承、无痛接入。
10. 作为用户，我希望按钮与弹窗文案跟随界面语言，从而中英文环境下都有正确提示。

## 实施决策

- **渲染器注册表**：以注册表描述图形化代码块渲染器（语言标识、渲染入口、按钮集、可导出格式等），按钮组/弹窗/禁点击/导出全部读注册表驱动；新渲染器登记即继承。接入清单写入文档（登记步骤、须补的测试惯例），注册表结构由契约测试钉住。
- **按钮注入**：复用代码块卡片的 hover 按钮模式——两视图共用按钮工厂、`mousedown preventDefault` 防抢焦点、内联 SVG 图标（不引入 codicon 字体依赖）、纯 CSS 悬停显隐。Live 侧在渲染 widget 内注入，阅读侧在挂载钩子注入（源锚点已有）。
- **Live 事件吞放**：呈现态渲染 widget 改为吞掉指向图形的鼠标事件；`edit` 按钮派发选区到围栏起点，触发现有「源码显形 + 卡片接管」管线，不新造编辑路径。
- **弹窗模块**：独立的全屏浮层模块，单例；取图与刷新共用「按围栏源码走渲染管线（缓存优先）」一条路径，不做 DOM 克隆同步。缩放/平移/contain-fit 的几何计算提取为纯函数。
- **导出通道**：消息协议新增导出请求/响应（沿用既有 reqId 请求/响应先例）；宿主侧校验载荷、`showSaveDialog`、落盘，失败经通知回报。SVG 序列化与 PNG 光栅化为 webview 侧纯函数。
- **i18n**：新增键进 `src/shared/locales/` 两语言包，编译期 parity 把关；manifest 侧无新命令。
- **主题联动**：弹窗与按钮配色走 CSS 变量明暗双套（既有 body class 机制），不随图表主题硬编码。

## 验证与完成条件

- **TDD 分层**：注册表契约测试（登记即继承按钮/弹窗/禁点击，含「假想第二渲染器」登记用例，不引入真实依赖）；弹窗几何纯函数（缩放锚点、范围钳制、contain-fit、平移边界）；SVG 序列化与 PNG 光栅化纯函数；禁点击与 edit 迁移的控制器级行为测试先暴露旧行为失败再实现。
- **浏览器回归**：弹窗交互（滚轮缩放、拖拽平移、Esc 关闭、焦点归还）与按钮 hover 显隐必须原生键鼠驱动验证（`test:browser`），合成事件测不到真实路径。
- **集成与视觉层断言**：按「视觉层断言（评审必查）」约定，至少一条集成断言落在绘制层探针（按钮可见性/悬停显隐、弹窗覆盖层存在且正文被遮蔽）；按钮与弹窗的关键 CSS 规则由契约测试钉住。
- **通用性验收**：接入清单文档落地，注册表契约测试覆盖假想渲染器继承路径。
- **回归与文档**：跑 compile、test:unit、test:browser、test:integration；依实际改动做安装态/打包检查（导出通道新增消息需过集成）。更新中英文 README、人工验证清单、文件树。自动验证不是用户验收——按钮观感、弹窗交互手感、导出文件可用性需用户人工确认。
- **风险显式化**：PNG 光栅化 CSP 验证结论（通过或降级）写入工单回报，不得静默砍功能。
