规格：[GitHub #72](https://github.com/ONEGAYI/vsidian/issues/72)。实施顺序：[#73 矩形选择与复制](https://github.com/ONEGAYI/vsidian/issues/73) → [#74 结构删除](https://github.com/ONEGAYI/vsidian/issues/74) → [#75 悬停控件与拖排](https://github.com/ONEGAYI/vsidian/issues/75)。本规格已获用户确认；实现与人工验收状态另记。

## 问题与目标
preview-5760 的表格跨格拖选、删除和控件交互未通过用户验收。本规格取代 #57 中不明确的“可见内容选择”解释，关联 #42/#43；不关闭或改写原票。用户已逐项确认并授权开票、实施。

## 已确认交互契约
1. 单格内保留普通文本编辑/选择；拖出单元格形成矩形单元格选区，统一淡色背景、外围主题色圆角边框，内部网格线可见。反向拖选同样有效。选区是高亮、复制、删除的共同依据。
2. 删除独立“选择第 x 列”按钮；行/列点阵把手紧贴表格左/上边沿，对准对应行/列，悬停显示。单击把手选择整行/列；拖动把手插入式移动整行/列，显示插入线，不做两位置交换，不是单格内容搬移。
3. 靠近底边显示新增行窄条，靠近右边显示新增列窄条，居中加号与相应提示；移入操作带保持显示，离开隐藏。平时操作带及边框不可见，不常驻占位。
4. Ctrl/Cmd+C 复制单元格区域时输出完整 Markdown 表格，选区第一行作为新表头，紧接正确分隔行；不附带未选中的原表头。格内局部文字保持普通复制。转义、空格、中文、内联格式不得被破坏。
5. Delete/Backspace：局部矩形清内容；覆盖完整行则删行；覆盖完整列则删列；覆盖整表（同时满行满列）优先删表。部分选区不得删掉未选内容或破坏语法。
6. 整行内容为空时，在最左格内容起点 Backspace 删除该行。删除表头后下一存活行晋升；删尽最后行/列时删除整表与分隔行，保护前后正文。
7. 表头可拖入数据区，数据行可拖到顶部；移动后首行就是表头，原表头进入数据区时成为普通行；分隔行永远在新表头后。列移动同步移动对应对齐信息。
8. 结构编辑经过既有宿主增量写回；一次撤销恢复整次操作；模式切换、失焦、外部文档同步不能留下错位/过期选区。保留 IME、普通格内输入、现有文本与表外选区行为。

输入一致性实现决策：格区仍有效时直接键入、粘贴或开始 IME 替换，应先清空所选格内容，再在区域起始格接收输入；不能悄悄取消高亮后变成前插。此路径保留行列结构，即使覆盖整行／整列也不复用 Delete 键的结构删除语义；不扩展为 Excel 区域粘贴。

## 用户故事
1. 作为编辑者，我希望跨格拖动形成矩形高亮，从而直接看到下一步操作的准确范围。
2. 作为编辑者，我希望复制任意格区得到独立 Markdown 表格，从而在其他文本编辑器中使用。
3. 作为编辑者，我希望局部清空与完整行列删除符合选择范围，从而保留未选数据。
4. 作为编辑者，我希望空行退格、表头晋升与最后行列删除自然衔接，从而把表格删干净。
5. 作为编辑者，我希望新增入口按边缘悬停显现，从而保持正文整洁。
6. 作为编辑者，我希望紧贴边沿的把手可点击选择、拖动重排，从而稳定操作行列。
7. 作为编辑者，我希望拖排表头仍产生有效表格，并可一次撤销，从而放心调整顺序。

## 实施决策
- 延续 CM6 全文模型/视口渲染与宿主权威文本路线；不另起富文本编辑器、不引入 Advanced Tables 运行依赖。
- 以 tableEditing/liveDecorations/tableControls/tableStructure/tableCells 现有边界为基础；可提取专门格区状态与纯结构规划模块，不复制多套选区状态。
- 纯函数负责结构变更与剪贴板序列化；统一选区由鼠标、把手和键盘消费；普通文本输入保持原语义。
- 拖排按真实坐标与稳定行列标识计算落点，必须支持沿把手栏拖动、重绘/滚动、取消和失焦。不要依赖直接派事件给目标行的假命中。
- 新行为覆盖已有错误断言，不能保留“同列拖选删除邻列”契约。保持已有同步、CRLF/LF、撤销及主题规则。
