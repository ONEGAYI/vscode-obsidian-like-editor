# MVP 规格：可切换阅读模式的 Markdown 实时预览编辑器

状态：产品基线于 2026-09-23 获批准；MVP 主要功能已实施，代理自动化回归通过。工单 #21–#25 跟进验收发现，真实输入操作与跨环境验收见 #26、#27，未执行项不视为用户验收。#29 的标记显形规则于 2026-09-24 获用户反馈「通过」。本文不授权发布市场或合并代码。

## 问题与目标

在 VSCode 内直接编辑现有 Markdown，提供类 Obsidian 的 Live Preview 和可切换阅读模式；支持真实文档所需的表格与双链，并兼容 Windows VSCode 1.86 和 Remote SSH 到 CentOS 7。

## 用户故事

1. 作为文档作者，我希望通过“重新打开方式”进入扩展并能回到源码编辑器，以便自行决定文件的编辑方式。
2. 作为中文用户，我希望输入、保存、撤销和重做稳定，以便放心处理真实文档。
3. 作为文档作者，我希望标题、粗斜体、列表、引用和代码在编辑时呈现格式，以便减少阅读语法标记的负担。
4. 作为读者，我希望切换到阅读模式并回到对应编辑位置，以便连续阅读和修改同一份未保存内容。
5. 作为任务记录者，我希望在两种模式下勾选或取消任务并能撤销，以便维护实际 Markdown 中的任务状态。
6. 作为文档作者，我希望查看普通链接和本地图片，并按模式约定打开链接，以便使用已有文档资源。
7. 作为笔记作者，我希望用 Obsidian 双链语法跳转笔记与标题，以便复用已有链接。
8. 作为笔记作者，我希望同名目标可选择、缺失目标有提示，以免打开错误文件或意外创建文件。
9. 作为表格作者，我希望直接编辑单元格、用 Tab 移动并增删行列，以便不必手工对齐整张表格源码。
10. 作为文档作者，我希望在编辑区查找文本，以便定位长文档内容。
11. 作为用户，我希望外部更新安全同步，冲突时保留我的未确认输入，以免被静默覆盖。
12. 作为旧版和远程用户，我希望安装 VSIX 后能编辑、保存并访问所属工作区资源，以便无需升级环境。
13. 作为包含复杂 Markdown 的文档作者，我希望暂不支持的语法保留原文并局部显示源码，以免普通编辑破坏内容。
14. 作为未来 CSS 片段使用者，我希望首版已有稳定的内容样式入口，以便二期引入 Obsidian 风格片段时不需要重做全部显示结构。
15. 作为长文档用户，我希望只为视口附近内容维护显示节点，查找与跳转仍覆盖全文，以便文档增大时不承担整篇 DOM 的布局成本。

## 功能契约

- 首版：标题、粗斜体、列表、任务、引用、行内与围栏代码、普通链接、本地图片、表格、基础双链和编辑区查找。
- Live Preview 的非活动区域呈现格式；进入对应内容时允许编辑语法。表格以单元格交互为主，不能用整表源码编辑替代。
- 阅读模式除任务勾选外只读。任务操作定位到当前文档中的具体范围，走共同保存、历史和冲突链路。
- 阅读模式单击链接跳转；实时预览中已渲染的普通链接与双链单击跳转，链接自身源码显形后普通单击保留编辑入口、Ctrl/Cmd+单击跳转。模式切换不触发保存、不生成文本历史，保留未保存内容并恢复对应段落/光标。标记显形的控制域见下方 #29 决议。
- 双链支持 `[[笔记]]`、`[[目录/笔记]]`、`[[笔记|显示文字]]`、`[[笔记#标题]]`。限定当前文件所属工作区文件夹，按需查找，不建持久索引；重名选择，缺失提示，不自动创建。
- 双链实现约束：扩展名省略时按 Markdown 文件处理；显式路径先精确解析（兼容文档相对及工作区相对候选），多个合法候选不得任意选中。无所属工作区时提示无法按工作区查找，保留链接文本。路径不能静默越过工作区边界。具体匹配和标题规范化规则须写入测试及文档。
- 表格首版支持普通 Markdown 表格、单元格输入、Tab/Shift+Tab 移动、显式增删行列；不包含合并单元格、拖拽调整和 Excel 式区域粘贴。单元格内管道符、转义和内联内容必须有保存回读测试。
- 无法安全应用外部更新或待确认输入时，保留恢复内容、暂停写回并提示；不得把“未实现协同编辑”解释为允许丢字。
- 新增语法显示不能改写未触碰文本。编码、换行和保存格式化影响需单独验证并说明。

### Live Preview 标记显形决议（#29）

标记的**控制域**是光标或非空选区进入后使该标记恢复源码显示的范围。折叠光标在范围两端也算进入；非空选区按区间相交判定。同一行不同语法各自判定，不因光标落在同一行就一起显示源码。

| 语法 | 光标在控制域外 | 单光标进入控制域 | 非空选区相交 |
| --- | --- | --- | --- |
| ATX 标题 `#`；Setext 标题下划线 | 标记隐藏，标题内容保留格式 | 整个对应标题为控制域：ATX 覆盖标题行，Setext 覆盖正文和下划线行 | 标题范围相交时显形该标题标记 |
| 粗体、斜体、行内代码 | 定界符隐藏，内容保留样式 | 仅进入对应的粗斜体或代码范围时显示该组定界符 | 仅相交的格式范围显形 |
| 无序列表、引用 | 行首标记及紧随空格隐藏；无序列表显示一个圆点 | 仅标记及相邻空格附近显形源码；无序列表同时撤下伪圆点 | 选区触及标记范围才显形 |
| 有序列表 | 编号及分隔符始终可见 | 保持可见 | 保持可见 |
| 任务 `[ ]` / `[x]` | 显示可操作的 checkbox | 进入任务标记范围后显示源码；列表标记仍独立判定 | 选区触及任务标记时显示源码 |
| 普通链接、自动链接、图片 | 链接显示文字并隐藏格式/目标；图片显示 widget | 进入该链接或图片范围（含左右边界）时显示完整源码；同行其他链接或图片不展开 | 仅相交的链接或图片显示源码 |
| 双链 `[[…]]` | 显示目标名称或别名 widget | 进入该双链范围（含左右边界）时显示完整源码 | 仅相交的双链显示源码 |
| 表格 | 单元格与管道符保持源文一维布局，管道符可见 | 在单元格内编辑，Tab/Shift+Tab 依表格导航规则移动 | 选区不切换整表源码形态 |
| 围栏及缩进代码 | 保持源码形态 | 保持源码形态 | 保持源码形态 |

源码始终是唯一文档内容；移动光标或选区只切换装饰，不写回文本，也不产生撤销历史。需要修改链接目标时，用方向键从邻近文字移入链接范围；源码显形后可用键盘编辑 `](url)`。渲染态普通单击跳转，源码态普通单击编辑，Ctrl/Cmd+单击始终可跳转。任务勾选和表格结构命令走既有宿主写回与撤销链路。未支持语法保留源码降级。

## 架构与实现边界

采用 CustomTextEditorProvider + Webview + CodeMirror 6；阅读渲染用 markdown-it，TextDocument 为权威文本。以宿主历史为准，避免两个独立的权威撤销栈。

逻辑职责包括文档会话、编辑显示、阅读渲染、链接/资源解析和样式契约；具体实现位于 `src/host/`、`src/webview/` 与 `src/shared/`，测试入口位于 `test/`。

输入请求携带会话、文档、事务及基准版本信息，宿主处理成功/失败确认和外部变更；重复、迟到与过期消息不能导致重复修改。仅检查版本不能替代同步设计。断连、隐藏、恢复和输入法组合期间均需验证待确认输入的生命周期。

资源用 URI 与宿主能力解析；限制 Webview 资源范围与 CSP，验证消息，不将 Markdown 原文作为可执行 HTML。自有阅读视图不默认继承其他 VSCode Markdown 插件。

一期样式要求：为两种模式的标题、任务、链接、表格等建立稳定类名/变量，核对 Obsidian 同款选择器并公布映射、验证样例与未覆盖项。不得仅在外围添加一个类就宣称全部兼容；也不要求兼容整个 Obsidian 应用 DOM。一期只用内部测试片段验证入口，不提供用户 CSS 加载界面。

最低宿主 VSCode 1.86；依赖锁定且前端产物满足该版本，运行期不依赖 CDN 或新系统原生库。以 Windows 便携版 1.86 为主要验收环境，Remote SSH 到 CentOS 7 做最小验证；环境不可用时记录未验证项。

## 验证与交付

### MVP 性能契约

编辑视图保留 CM6 全文文本模型与视口渲染；StateField/直接装饰处理布局相关信息，纯显示装饰按实际可见范围更新。正常键入路径不能逐次重建全文 DOM、全部装饰或发送完整快照；必要的初始化和重同步除外。

阅读视图独立分块按需挂载与回收，保留源位置锚点及任务语义。允许必要全文语义解析，不要求读取文件流式化，也不以只隐藏全文 DOM 代替按需创建。CSS 兼容表注明虚拟化与跨屏结构选择器的冲突。

固定视口的同构短行样例按 1千/1万/10万行测试：体量增长 10 倍时内容 DOM 数量不超过 2 倍，明确有界例外；往返滚动 10 次后节点/重型实例能回收到基线附近。此为工程门槛而非官方已测数据。输入、打开与切换耗时记录基准，原型票中锁定延迟预算；另测超长行、图片密集、超大单表/代码块。查找与标题跳转必须定位屏外内容。

实现依据见[视口渲染补充调研](../research/obsidian-viewport-rendering.md)。

### 功能与运行验证

所有可执行行为先写契约测试并确认失败，再实现。优先通过文档修改/视图操作的公开入口验证，不为实现细节制造大量 mock。

- 自动化：输入增量、版本冲突、撤销重做、任务定位、双链解析、表格回读、两种渲染语义、稳定选择器。
- 真实宿主：中文 IME、emoji、拖选、跨块复制粘贴、快捷键、图片加载导致的滚动变化、模式切换、隐藏恢复。
- 文档样例：CRLF/LF、末尾换行、尾部空格、frontmatter、未知语法、重复任务、重复标题、同名文件、转义表格、代码块内伪语法。
- 性能档位：10 KB、100 KB、1 MB 文档，记录打开、输入和切换表现，不编造既定延迟承诺。
- 打包：交付 VSIX、安装与切换说明、功能及降级边界、旧版与远程验证记录。初始注册为可选编辑器，不自动修改默认打开设置。
