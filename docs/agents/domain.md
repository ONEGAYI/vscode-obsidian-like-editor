# 领域文档约定

当前项目为单个 VSCode 扩展，采用单一领域上下文，不引入多上下文目录。

## 阅读入口

- 根目录 `CONTEXT.md`：记录已确定的领域术语、功能边界与核心规则。
- `docs/adr/`：记录已确定的架构决策及其依据。

以上文件按需创建。文件尚不存在时直接继续工作，不为补齐结构创建空文档；技术栈与功能范围明确后再记录实际决策。

## 维护方式

探索相关代码前，读取已有领域文档与相关架构决策。Issue、规格、代码和解释中使用已定义的术语；发现术语缺口时，在明确含义后补充。

新方案若与已有架构决策冲突，应说明冲突及重新讨论的理由，不静默覆盖原有决定。
