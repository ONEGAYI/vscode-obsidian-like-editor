# MVP 将全文文本模型与视口 DOM 渲染分离

## 状态

已接受的用户要求：2026-09-23，视口按需渲染必须纳入 MVP。阅读分块方案为本次落实该要求的工程决定，不代表 Obsidian 阅读实现的事实。

## 决定

CM6 承载全文编辑模型，保留其视口渲染；自定义装饰、图片和表格遵守布局及实例生命周期约束。阅读视图以独立的分块按需挂载实现，不一次常驻整篇 DOM。不得以流式读取文件描述此架构。

## 影响与取舍

新增源位置到块的映射、高度估计、动态测量和回收验证成本；换取长文档 DOM 不随全文线性增长的可验证约束。文档模型、解析、撤销历史仍可能随内容增长；需要分别测量。

CSS 稳定入口同时保留，但不能承诺依赖全文 DOM 兄弟关系的所有 Obsidian 片段完全兼容。超大单表/代码块需单独评估，不以总文档虚拟化掩盖块内成本。

验收样例及一手来源见[补充调研](../research/obsidian-viewport-rendering.md)。
