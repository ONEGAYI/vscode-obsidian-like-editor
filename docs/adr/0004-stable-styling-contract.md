# 一期建立稳定样式入口，为二期 Obsidian CSS 片段兼容预留

## 状态

已接受，2026-09-23。用户确认 MVP 时追加二期自定义 CSS 片段与 Obsidian 同款选择器，并要求一期前端留口。

## 决定

一期在实时预览与阅读视图建立明确、稳定、可测试的内容样式入口；实现时核对并记录 Obsidian 对应选择器及变量。内部结构可演进，但不能无记录地破坏公开样式入口。对已交付语法逐项验证，新增表格、双链等功能时同步扩展兼容表。

二期实现 CSS 片段的配置、加载和应用。三期仅考察“插件上插件”，一期不建设通用插件框架。

## 取舍与边界

稳定选择器会约束前端 DOM 重构，但可减少二期为了兼容已有样式而重做视图的成本。兼容范围以实际映射与测试结果公开，不把 Obsidian 窗口布局、核心插件或第三方插件私有 DOM 一并视为已兼容。

一期用内部固定测试样式证明入口可用，不开放用户片段加载。二期再明确 CSS 外部资源、安全策略、作用域与优先级。

官方 CSS 片段资料仅作为格式与行为参考，不证明本项目已有兼容能力：[Obsidian CSS snippets](https://obsidian.md/help/snippets)。
